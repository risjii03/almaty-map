# Карта заказов — Алматы

Статическая страница (Leaflet): тепловая карта, соты, точки, фильтры по району и периоду.

- `index.html` — сама карта
- `data.json` — данные (выгружаются из Google Sheets: меню «Карта Алматы» → «Выгрузить data.json»)

Обновление данных: выгрузить новый `data.json` и заменить файл в репозитории.
